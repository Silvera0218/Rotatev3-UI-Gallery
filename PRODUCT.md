# ROTATION V3 UI Gallery

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML, CSS and JavaScript, following the referenced V2 gallery. The WebGL selection material is bundled from apple-liquid-glass-webgl. GitHub Pages hosts the built static files.

## Users

The game's art and interaction collaborators. The user explicitly selected art and interaction handoff as the documentation purpose.

## Product Purpose

Present current ROTATION V3 interface screenshots with their entry points, controls, states and motion behavior. Let collaborators browse categories and enlarge screenshots while reading the relevant specification.

## Capabilities and Constraints

Create a new public repository under Silvera0218 and publish a Pages URL, modeled on https://silvera0218.github.io/Rotatev2-UI-Gallery/. Capture the current local V3 game in isolated QA browser contexts. Document implemented behavior. The current V3 contains tools and special blocks; its modification system has been removed at the user's request.

## Evidence on Hand

Game source: the Rotation project's rotationV3 directory. Screenshot state, origin and capture settings are recorded in data/screens.json and each PNG's metadata.

## Product Principles

- Let real interface screenshots lead.
- Explain entry, action, state, and motion in concrete Chinese.
- Keep browse and image-viewer controls accessible on desktop and mobile.
- Follow the V2 reference gallery's light visual language and category navigation.
